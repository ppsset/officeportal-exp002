# WAG Portal

A lightweight, responsive single-page experience for the WAG MEP design office. The portal highlights all major modules—office pulse, tech workshop, shared facility, defect tracker, leave requests, suggestion box, and combined Well & Green insights—with sample data, detail overlays, and a simple sign-in flow for general users and managers.

## Running the prototype
Open `index.html` in your browser. All data is mocked locally, and external images use lightweight placeholders for quick loading.
